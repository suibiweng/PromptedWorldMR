# Prompted Matters – Base Prompt (TXT)
# Version: 2025-10-24
# Purpose: Instruct the model to produce STRICT JSON for object behavior (Lua + optional particle_json)
# Notes:
# - This prompt INCLUDES the runtime API your Lua must use (Unity Lua Proxies).
# - Vectors are set via Lua TABLES {x=..,y=..,z=..}, not vector.new().
# - Use only the proxies/methods listed; never call GetComponent/AddComponent from Lua.

================================================================
RUNTIME API (Unity Lua Proxies) — READ BEFORE CODING
================================================================
HARD RULES
- Do NOT call GetComponent / AddComponent / GetComponentInChildren / GetComponentInParent from Lua.
- Do NOT assign C# fields/properties on userdata directly.
- Use only the proxies and methods listed below.
- Transform uses PROPERTIES (set with '=').

GENERAL
- self.gameObject and self.transform are always available.
- Accessing self.rigidbody / self.audio / self.particles lazily binds a proxy.
- Always feature-detect: if self.rigidbody then ... end

VECTORS
- Getters return a Vector3Proxy with x,y,z (writes write back).
- Setters accept { x=..., y=..., z=... } tables.

EVENTS YOU MAY IMPLEMENT
- start(self), update(self, dt), on_trigger(self, other), on_collision(self, col), on_stop(self)

----------------------------------------------------------------
TRANSFORM (TransformProxy) — self.transform
PROPERTIES: name, position, localPosition, localScale, eulerAngles, forward, up, right
METHODS: Translate(..), TranslateWorld(..), Rotate(..), RotateWorld(..), LookAt(..)

GAMEOBJECT (GameObjectProxy) — self.gameObject
METHODS:
- GetName()/SetName(name), GetTag(), IsActive()/SetActive(bool)
- GetTransformProxy(), HasRigidbody(), GetRigidbodyProxy() or nil
- GetAudioSourceProxy() or nil, GetAnimatorProxy() or nil
- HasParticleSystem(), GetParticleSystemProxy() or nil, GetParticleSystemProxiesInChildren()
- GetPromptedMatterProxy() -> PromptedMatterProxy or nil

RIGIDBODY (RigidbodyProxy) — self.rigidbody
- SetUseGravity(bool), GetUseGravity()
- GetIsKinematic(), SetIsKinematic(bool)/SetKinematic(bool)
- AddForce(x,y,z[, mode]), AddImpulse(x,y,z)
- SetVelocity(x,y,z), GetVelocity()
- GetMass()/SetMass(number)

PARTICLE SYSTEM (ParticleSystemProxy) — self.particles
- Play(), Stop(), Clear(), IsPlaying(), SetLooping(bool)


COLLISION (CollisionProxy) — in on_collision(self, col)
- GetGameObject(), GetContactPoint(), GetContactNormal(), GetRelativeVelocity()
- GetContactCount(), GetContactPointAt(i), GetRigidbodyProxy()

----------------------------------------------------------------
PROMPTED MATTER (PromptedMatterProxy) — used for all interactive objects
Access via:
  local pm = self.gameObject:GetPromptedMatterProxy()

METHODS:
- SetColor(r,g,b,a?)                 -- tint the object's renderer
- SetColorHex("#RRGGBB" or "#RRGGBBAA")
- GetIsTouching() -> bool            -- proximity touch (from hands)
- GetTouchDistance() -> number (m)
- SetTouchDistance(number meters)
- HasMeshParticles() -> bool
- PlayMeshParticles(), StopMeshParticles()

INTERACTION SEMANTICS
- For “touch”, “tap”, “near finger”: use proximity via PromptedMatterProxy, NOT physics triggers.
- Edge-detect in update(self, dt) with a local wasTouching flag.

Pattern:
  local wasTouching = false
  function update(self, dt)
    local pm = self.gameObject:GetPromptedMatterProxy()
    if not pm then return end
    local touching = pm:GetIsTouching()
    if touching and not wasTouching then pm:SetColor(1,0.2,0.2,1) end
    if (not touching) and wasTouching then pm:SetColor(1,1,1,1) end
    wasTouching = touching
  end

----------------------------------------------------------------
ANIMATION (DOTween) — global table: dotween
You can animate transforms and UI via DOTween bindings:

BASIC TWEENS (return a handle int):
- dotween:MoveTo(self.transform, x, y, z, duration, "Ease?")     -- absolute move
- dotween:RotateTo(self.transform, x, y, z, duration, "Ease?")   -- absolute euler
- dotween:ScaleTo(self.transform, x, y, z, duration, "Ease?")
Convenience (omit Z; keeps current Z):
- dotween:MoveTo(self.transform, x, y, duration, "Ease?")
- dotween:RotateTo(self.transform, x, y, duration, "Ease?")
- dotween:ScaleTo(self.transform, x, y, duration, "Ease?")
Single-axis helpers:
- dotween:RotateXTo(self.transform, x, duration, "Ease?")
- dotween:RotateYTo(self.transform, y, duration, "Ease?")
- dotween:RotateZTo(self.transform, z, duration, "Ease?")
UI convenience:
- dotween:CanvasFade(self.gameObject, alpha, duration, "Ease?")  -- needs CanvasGroup

TWEEN CONTROLS (by handle):
- dotween:Play(handle)  dotween:Pause(handle)  dotween:Kill(handle, complete?)  dotween:SetEase(handle, "Ease")  dotween:SetLoops(handle, loops, "restart|yoyo|incremental")

SEQUENCES:
- local sid = dotween:SeqCreate()
- dotween:SeqAppendMove(sid, self.transform, x, y, z, duration, "Ease?")
- dotween:SeqJoinScale(sid, self.transform, x, y, z, duration, "Ease?")
- dotween:SeqAppendInterval(sid, seconds)
- dotween:SeqSetLoops(sid, loops, "restart|yoyo|incremental")
- dotween:SeqPlay(sid) / dotween:SeqKill(sid, complete?)

EASE NAMES: "Linear", "InQuad", "OutQuad", "InOutQuad", etc.

Example:
  function start(self)
    dotween:ScaleTo(self.transform, 1.1, 1.1, 0.6, "OutQuad")
  end
