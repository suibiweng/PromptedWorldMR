### RUNTIME API (Unity Lua Proxies) — READ BEFORE CODING

HARD RULES
- Do NOT call GetComponent / AddComponent / GetComponentInChildren / GetComponentInParent from Lua.
- Do NOT assign C# fields/properties on userdata directly (e.g., `rigidbody.useGravity = true` is INVALID).
- Use only the proxies and methods listed below.
- Transform uses PROPERTIES (set with `=`), not "SetXxx" methods.

Valid examples:
  self.transform.name = "MyObject"
  self.transform.localScale = { x=1, y=1, z=1 }
  self.rigidbody:SetUseGravity(true)
Invalid examples:
  self.transform:SetName("MyObject")
  self.transform:SetLocalScale({x=...,y=...,z=...})
  self.transform:SetColor({...})
  self.rigidbody.useGravity = true

GENERAL
- self.gameObject and self.transform are always available.
- Accessing self.rigidbody / self.audio (audioSource) / self.particles (particleSystem) lazily binds a proxy.
  If missing, the runtime may auto-add a safe default (Rigidbody is kinematic + no gravity by default).
- Always feature-detect: `if self.rigidbody then ... end`.

VECTORS
- Getters like `transform.position` return a Vector3Proxy with fields `x, y, z` (writes write back).
- Setters accept `{ x=..., y=..., z=... }`.

EVENTS TO IMPLEMENT (optional)
- start(self), update(self, dt), on_trigger(self, other), on_collision(self, col), on_stop(self)

function start(self)
  self.transform.name = "ProgramableObject_Virtual"
  self.transform.localScale = { x = 1, y = 1, z = 1 }

  local po = self.programable or self.programmable or self.programableObject
  if po then po:SetColor(1, 0, 0, 1) end

  dotween:ScaleTo(self.transform, 1.5, 1.5, 1.5, 0.5, 'InOutSine')
end

function update(self, dt)
  local s = self.transform.localScale
  if s.x >= 1.5 then
    dotween:ScaleTo(self.transform, 1, 1, 1, 0.5, 'InOutSine')
  elseif s.x <= 1.0 then
    dotween:ScaleTo(self.transform, 1.5, 1.5, 1.5, 0.5, 'InOutSine')
  end
end

### INTERACTION SEMANTICS (VERY IMPORTANT)

When the user says “touch”, “tap”, “poke”, “finger near”, or similar, you MUST use the
ProgramableObject proximity API, NOT physics triggers/collisions.

- Proximity touch = `ProgramableObjectProxy:GetIsTouching()` (returns bool).
- Implement proximity reactions inside `update(self, dt)` using EDGE DETECTION:
  track when the touching state changes from false→true (touch enter) and true→false (touch exit).

Only use `on_trigger(self, other)` if the user explicitly mentions a trigger collider.
Only use `on_collision(self, col)` if the user explicitly mentions rigidbody collisions.

#### REQUIRED PATTERN for “when I touch it …”
```lua
-- locals at top-level are preserved across frames
local wasTouching = false

function start(self)
  -- optional init, like naming or scaling
  self.transform.name = self.transform.name or "ProgramableObject"
end

function update(self, dt)
  local po = self.programable or self.programmable or self.programableObject
  if not po then return end

  local touching = po:GetIsTouching()

  -- Touch ENTER (false -> true)
  if touching and not wasTouching then
    -- Example: change to red instantly
    po:SetColor(1, 0, 0, 1)
    -- Or, if tween available:
    -- po:TweenColor(1, 0, 0, 1, 0.25, "InOutSine")
  end

  -- Touch EXIT (true -> false)
  if (not touching) and wasTouching then
    -- Example: revert to white
    po:SetColor(1, 1, 1, 1)
    -- Or tween back:
    -- po:TweenColor(1, 1, 1, 1, 0.25, "InOutSine")
  end

  wasTouching = touching
end

function on_trigger(self, other) end   -- NOT used for proximity "touch"
function on_collision(self, col) end   -- NOT used for proximity "touch"
function on_stop(self) end

### PRONOUN & TONE REWRITE FOR LABELS (MANDATORY)

Goal: When a user addresses the object with first-person language (e.g., "tell me …", "say that I'm …"), the label should speak back to the user in second person ("you"), not mirror the user's words.

Rewrite rules:
- First person → second person for the user:
  - "me" → "you"
  - "I am" / "I'm" → "you are"
  - "my" → "your"
- Keep the rest of the phrase intact; fix simple casing ("i'm" → "I'm") before rewriting.
- Use plain ASCII quotes (no smart quotes). Keep punctuation simple; end with a period unless the prompt clearly implies a question mark.

Examples (apply once in `start`, not event-gated):
- "tell me i'm pretty"  → SetLabel("You are pretty.")
- "tell me I am fast"   → SetLabel("You are fast.")
- "say that I'm awesome"→ SetLabel("You are awesome.")
- "tell me your name"   → SetLabel("My name is <name>.")  // name/ID follows existing policy

Do NOT:
- Do not echo first-person back to the user (avoid "I am pretty" or "Tell me I'm pretty").
- Do not introduce state variables (no `intent`, no `lastIntent`) unless explicitly requested.
- Do not spam SetLabel every frame for these one-shot phrases.
