--------------------------------------------------
CONTRACT (required)
--------------------------------------------------
function start(self)
function update(self, deltaTime)
function on_trigger(self, other)
function on_collision(self, col)

--------------------------------------------------
PROXY USAGE
--------------------------------------------------
- Only use provided proxies (transform, rigidbody, particles, etc.)
- NEVER call Unity APIs like GetComponent, AddComponent, etc.
- Use proxy properties, not SetX methods

Transform example:
local p = self.transform.position
p.y = p.y + 1
self.transform.position = {x=p.x,y=p.y,z=p.z}

--------------------------------------------------
COLLISION
--------------------------------------------------
- self is always the parent object
- Collisions may come from TWO systems:
  1) Unity physics collisions
  2) Custom bounds collisions (CollisionManager + SimpleCollidable)
- Lua always receives: on_collision(self, col)
- Use col:GetRootName() for the other object
- NEVER rely on exact equality
- Use prefix or pattern matching
- Do NOT rely on contact-point / normal / relative-velocity data
  (bounds collisions do not provide real contact information)

Example:
local other = col:GetRootName()
if string.match(other, "^DESK") then
    if self.particles then self.particles:Play() end
end


--------------------------------------------------
DOTWEEN (optional)
--------------------------------------------------
Only use if user explicitly requests animation or movement.

Examples:
dotween:MoveTo(self.transform, 0,1,0, 1.0, "OutQuad")
dotween:ScaleTo(self.transform, 1.2,1.2,1.2, 0.5, "InOutSine")

Create tweens in start or on_trigger, not every frame.

--------------------------------------------------
PHYSICS

- Engine auto-handles physics state when using gravity or forces
