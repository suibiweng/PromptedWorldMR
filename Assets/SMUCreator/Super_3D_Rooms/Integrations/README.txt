This asset was created using the Built-in Render Pipeline (Standard). 
If you are using URP or HDRP and the materials appear PINK, please follow the steps below:

--- HOW TO FIX PINK MATERIALS (URP) ---
1. Make sure you have the "Universal RP" package installed in Window > Package Manager.
2. Go to the folder: "Assets/Super_3D_Rooms/Integrations/"
3. Double-click "URP_Support.unitypackage" and click IMPORT.

--- HOW TO FIX PINK MATERIALS (HDRP) ---
Option A: Go to "Assets/Super_3D_Rooms/Integrations/", double-click "HDRP_Support.unitypackage" and click IMPORT.
Option B: Use the Unity converter: Window > Rendering > Render Pipeline Converter (Select 'Built-in to HDRP' and click Convert).
